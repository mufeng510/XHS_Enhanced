内容库连接

用于把笔记一键保存到你通过 Docker 自建的 XHS_ALL_IN_ONE 内容库。部署后端默认只允许 localhost 的跨域来源，所以保存请求由扩展的后台服务发出，并需要你授予该服务器的访问权限（只在本页点击“测试连接”或“保存”时申请）。

该地址是明文 http，用户名与密码会以明文传输给服务器。仅建议在可信局域网内使用；如服务器暴露于不受信任的网络，请改用 HTTPS（反向代理/自签证书均可）。

隐私说明

  • 服务器地址、用户名、账号 ID、密码与 refresh token 都只保存在扩展的本地存储（chrome.storage.local）中，网页脚本无法读取。
  • 笔记链接只会发送到你在此填写的服务器，不会发送到任何第三方。
  • 扩展只在小红书网页（xiaohongshu.com）生效；封面读取仅访问小红书图片 CDN。
  • 密码保存在浏览器中且会发送到你的服务器用于登录；请只填写你信任的自建实例。
