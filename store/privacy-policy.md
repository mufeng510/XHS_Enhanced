# 隐私政策 — 小红书网页版增强

生效日期：2026-11-14

“小红书网页版增强”（以下简称“本扩展”）是一个浏览器扩展，用于在小红书网页版中高亮热门笔记、快速跳转、复制链接与封面、下载无水印封面、批量勾选并下载选中笔记的图片（封面/内图/全部，打包为 zip 保存到本地），并可将笔记链接保存到用户自建的内容库服务（XHS_ALL_IN_ONE）。

## 我们收集什么

**什么都不收集。** 本扩展没有服务器，不接收、不存储、不分析任何用户的个人信息，也不包含任何统计、广告或崩溃上报 SDK。

具体而言：

- 不读取、不导出小红书账号密码、Cookie 或会话凭据；
- 不收集浏览历史、搜索关键词、笔记内容或点赞数据；
- 不向任何第三方发送数据；无任何“回传”“遥测”“埋点”行为；
- 不使用 `cookies` 权限，不申请 `tabs`、`webRequest` 或 `<all_urls>` 权限。

## 本地存储了什么

以下数据只保存在用户本机：

- 内容库（XHS_ALL_IN_ONE）连接配置：服务器地址、用户名、小红书 PC 端账号 ID、密码、refresh token —— 写入 `chrome.storage.local`，不与账号同步，网页脚本无法读取；
- 热门阈值、「只显示热门」开关状态、批量下载范围（封面/内图/全部）与组织方式（按笔记文件夹/平铺单层） —— 保存在扩展本地存储 `chrome.storage.local`，不与账号同步，网页脚本无法读取；
- 批量勾选的笔记列表 —— 仅保存在浏览器会话级存储（`chrome.storage.session`），浏览器关闭后自动清空，不与账号同步，不含任何账号或凭据。

这些数据只用于向用户自己填写的内容库服务器发起登录和采集请求，且仅在用户主动点击“保存入库 / 保存到内容库 / 本页全部入库 / 测试连接”时发送。用户可随时在选项页点击“清除设置”删除内容库设置并撤销对该服务器的授权。

## 笔记链接何时、发往哪里

仅在用户主动点击保存按钮时，扩展把笔记分享链接（如 `https://www.xiaohongshu.com/explore/<id>?xsec_token=...`）发送到**用户在选项页自行填写**的服务器。该服务器由用户自己部署，扩展作者无法访问。扩展不会把链接发送到任何其他地方。

## 封面与内图图片

用户点击“复制封面 / 下载封面”，或勾选笔记后点击批量下载时，扩展仅从小红书图片 CDN（`xhscdn.com`、`xiaohongshu.com` 子域）读取图片字节，用于写入剪贴板、保存到本地或打包成 zip 后保存到本地。图片字节不发送到任何第三方，不用于识别、指纹或追踪。zip 文件仅在用户本机生成，由浏览器直接下载到本地，不经过任何第三方服务器。

## 权限的用途

见仓库 `store/permissions.md`（与 Chrome Web Store / Edge Add-ons 提交时填写的权限理由一致）。

## 远程代码

本扩展不加载任何远程托管代码；所有逻辑随扩展包分发，扩展包完整、可审计（源码见 https://github.com/mufeng510/XHS_Enhanced ）。

## 儿童隐私

本扩展不针对、也不 knowingly 收集 13 岁以下儿童的任何数据（本扩展本来就不收集任何数据）。

## 变更与联系

本政策如有变更，将更新于本文件并随扩展版本发布说明一并公布。
