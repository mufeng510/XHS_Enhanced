#  Chrome Web Store / Edge Add-ons 上架文案

## 名称

小红书网页版增强

## 简短描述（≤132 字符，中英两版可选其一）

小红书网页版高亮热门笔记，批量勾选下载笔记图片（封面/内图/全部），一键跳转与复制，保存到自建内容库。

English (optional): Highlight trending notes on Xiaohongshu web, batch-download note images (cover/inner/all), jump & copy, save to your self-hosted library.

## 详细描述

在小红书网页版中快速识别真正热门的笔记，并一键完成复制、下载、入库。仅在小红书网页（xiaohongshu.com）生效，不收集任何用户数据。

功能：

- 高亮点赞数严格超过自定义阈值（默认 100）的笔记卡片，阈值与内容库共用扩展选项页，保存在扩展本地存储，保存后所有已打开的小红书页面立即生效；
- 首页 feed、搜索结果页、用户主页均可用；
- 右上角提供「上一条热门笔记 / 下一条热门笔记」悬浮按钮，平滑滚动、自动跳过当前可见内容；
- 「只显示热门」开关：未达阈值的卡片模糊虚化（保留占位，悬浮可看清，卡片按钮仍可用）；
- 笔记卡片悬浮显示四个按钮：「复制链接」（explore 格式，含 xsec_token）、「复制封面」（无水印封面写入剪贴板）、「下载封面」（无水印封面原图保存到本地）、「保存入库」；
- **批量勾选并一键下载笔记图片**：卡片右上角复选框任意多选，底部批量栏提供「全选已加载」（再点取消）、「连续勾选」（开启后瀑布流滚动加载的新卡自动勾选）、「清空」；下载范围三档「只封面 / 只内图 / 全部」（全页面共享生效）；
- 批量产物为单个 zip：默认**全部平铺单层**（文件名带序号与笔记 ID，不重名），也可在选项页「批量下载」切换为每篇笔记一个文件夹（封面为 `01_封面.jpg`，内图 `02…`）；zip 内图片为 JPEG/原生格式，超过 200MB 自动分卷；勾选列表仅存浏览器会话级存储（关闭即清空）；
- **内图来自笔记详情页**（后台服务带登录态直拉详情页 HTML，失败时退化为后台隐藏标签页读取）；视频笔记没有内图，「只内图」时自动跳过并计数提示；
- 一键保存到自建内容库（XHS_ALL_IN_ONE）：卡片级「保存入库」、笔记详情页「保存到内容库」、列表页「本页全部入库」（自动分批）；
- **商品详情页下载高清商品图**：在 `/goods-detail/*` 页面右侧注入悬浮面板，一键扫描商品高清图（含懒加载追加的图），自动去重、排除头像/表情等修饰图（可手动包含），支持高清 PNG（默认）/ 原始格式 / JPEG q90；“主图压缩到 3MB 以内”开关（默认开启，超限主图下载时重新编码为 JPEG 直至 ≤3MB）；按页面位置自动分区命名 `主图_01.png` / `详情图_01.png` / `其它_01.png`；打包为单个 zip（附商品信息文件与分区计数）一次性保存到本地，超过 200MB 自动分卷；
- 内容库设置与热门阈值位于扩展选项页：配置服务器地址、用户名、密码，点击「测试连接」自动发现已绑定的小红书 PC 端账号；密码等凭据只保存在浏览器本地存储中；
- 自动处理首屏内容、无限滚动新增内容和站内页面导航（SPA）。

隐私：不收集、不上传任何用户数据。笔记链接仅在用户主动点击保存时，发送到用户自己填写的自建内容库服务器；封面/内图的图片字节仅从小红书图片 CDN 读取；批量 zip 仅在本机生成后交给浏览器下载保存。详见隐私政策。

## 分类与语言

- 分类：工具（Tools / Utilities）
- 语言：中文（简体）

## 单一用途（Single purpose）

在小红书网页版中，帮助用户识别和批量处理热门笔记（高亮、跳转、复制、批量下载笔记图片、保存到自建内容库），并在商品详情页批量下载商品高清图片。

## 不使用远程代码

所有逻辑随扩展包分发，不加载任何远程托管代码；不使用 `eval` / `new Function`。
