#  Chrome Web Store / Edge Add-ons 上架文案

## 名称

小红书网页版增强

## 简短描述（≤132 字符，中英两版可选其一）

小红书网页版搜索/主页/首页高亮热门笔记，一键跳转与复制，支持无水印封面下载和保存到自建内容库。

English (optional): Highlight popular notes on Xiaohongshu web, jump/copy with one click, download watermark-free covers, save to your self-hosted library.

## 详细描述

在小红书网页版中快速识别真正热门的笔记，并一键完成复制、下载、入库。仅在小红书网页（xiaohongshu.com）生效，不收集任何用户数据。

功能：

- 高亮点赞数严格超过自定义阈值（默认 100）的笔记卡片，阈值可在页面右上角随时调整，即时生效；
- 首页 feed、搜索结果页、用户主页均可用；
- 右上角提供「上一条热门笔记 / 下一条热门笔记」悬浮按钮，平滑滚动、自动跳过当前可见内容；
- 「只显示热门」开关：未达阈值的卡片模糊虚化（保留占位，悬浮可看清，卡片按钮仍可用）；
- 笔记卡片悬浮显示四个按钮：「复制链接」（explore 格式，含 xsec_token）、「复制封面」（无水印封面写入剪贴板）、「下载封面」（无水印封面原图保存到本地）、「保存入库」；
- 一键保存到自建内容库（XHS_ALL_IN_ONE）：卡片级「保存入库」、笔记详情页「保存到内容库」、列表页「本页全部入库」（自动分批）；
- 内容库设置位于扩展选项页：配置服务器地址、用户名、密码，点击「测试连接」自动发现已绑定的小红书 PC 端账号；密码等凭据只保存在浏览器本地存储中；
- 自动处理首屏内容、无限滚动新增内容和站内页面导航（SPA）。

隐私：不收集、不上传任何用户数据。笔记链接仅在用户主动点击保存时，发送到用户自己填写的自建内容库服务器；封面图片字节仅从小红书图片 CDN 读取。详见隐私政策。

在小红书网页版中，帮助用户识别和批量处理热门笔记（高亮、跳转、复制、下载封面、保存到自建内容库）。

## 不使用远程代码

所有逻辑随扩展包分发，不加载任何远程托管代码；不使用 `eval` / `new Function`。
